# Delegate support

Delegate is an unofficial mobile app (iPhone, iPad, and Android) for [Manager.io](https://www.manager.io), on both self-hosted Manager Server and Manager Cloud. It isn't made, endorsed, or supported by Manager.io.

This repository is for **bug reports and feature requests** only. The app's source code isn't public.

- **Something not working?** [Report a problem](../../issues/new?template=bug.yml)
- **Have an idea?** [Request a feature](../../issues/new?template=feature.yml)
- **Prefer email?** Write to contact@getdelegateapp.com

Before opening an issue, please search the [existing issues](../../issues). If yours is already there, add a 👍 to it instead.

Questions about Manager itself (your accounts, reports, or server) belong with [Manager.io](https://www.manager.io), not here.

## Keep your data private

Issues here are public. Never post your server address, access token, passwords, or business details. Screenshots are welcome, but cover any names, amounts, or addresses you don't want shared.

See the [Delegate privacy policy](https://getdelegateapp.com/privacy) for how the app handles your data.
